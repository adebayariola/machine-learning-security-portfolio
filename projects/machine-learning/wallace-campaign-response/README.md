# Telecommunications Campaign Response Classification

[← Portfolio home](../../../README.md) · [Machine Learning projects](../../../README.md#machine-learning)

> **Publication status:** Project summary; source not published.

## Research question

Which Wallace Communications customers are likely to accept a new contract?

## Dataset

Wallace Communications; wallacecommunications.csv; 50,662 customer records

## Tools and methods

Python, pandas, scikit-learn, neural classifiers and Jupyter

## What I implemented

- Cleaned customer records, standardised categories, handled unknown values and encoded features to predict uptake of a new mobile contract.
- Compared Logistic Regression, neural networks and decision trees across hyperparameter settings; presented ROC curves, confusion matrices, AUC, precision, recall and F1.

## Results and limitations

The submitted metric table and confusion matrix differ, so the CV avoids a numerical performance claim.
