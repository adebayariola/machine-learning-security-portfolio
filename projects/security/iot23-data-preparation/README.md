# IoT Malware Traffic Data Preparation

[← Portfolio home](../../../README.md) · [Security projects](../../../README.md#security)

> **Publication status:** Project summary; source not published.

## Research question

How can labelled IoT traffic be prepared for downstream intrusion detection?

## Dataset

IoT-23 labelled network traffic

## Tools and methods

Python, pandas and Jupyter Notebook

## What I implemented

- Prepared labelled traffic records in batches, organised examples by traffic label and implemented class-balancing, cleanup and consolidation into per-label CSV files.
- Documented the IoT-23 data source and created reusable preparation steps for downstream intrusion-detection experiments.
