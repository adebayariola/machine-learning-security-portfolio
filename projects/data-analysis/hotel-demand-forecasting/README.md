# Hotel Room Demand Forecasting

[← Portfolio home](../../../README.md) · [Data Analysis projects](../../../README.md#data-analysis)

> **Publication status:** Project summary; source not published.

## Research question

How can a monthly hotel-demand series be modelled and forecast?

## Dataset

Course-generated monthly hotel-demand series; 100 observations

## Tools and methods

Python, time-series decomposition, ADF testing, SARIMAX and Auto ARIMA

## What I implemented

- Decomposed trend and seasonality, checked stationarity, applied differencing and examined ACF/PACF plots before fitting forecasting models.
- Compared SARIMAX and Auto ARIMA using a chronological train/test split, forecast errors and future-demand plots.

## Results and limitations

Generated-data coursework, not a production hotel dataset.

This publication currently contains a project description only. Source files and executable results are not included here.

## Data access and attribution

Raw datasets, trained model binaries and private operational records are not redistributed. Dataset ownership remains with the respective providers. Where upstream research implementations were adapted, the description distinguishes those methods from local engineering contributions.
