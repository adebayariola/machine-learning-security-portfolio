# Customer Churn Score Modelling

[← Portfolio home](../../../README.md) · [Data Analysis projects](../../../README.md#data-analysis)

> **Publication status:** Project summary; source not published.

## Research question

How do boosting regressors estimate a continuous customer churn score?

## Dataset

Course-generated customer attributes and continuous churn scores; 1,000 customers

## Tools and methods

Python, LightGBM, XGBoost and regression evaluation

## What I implemented

- Compared boosting models for continuous churn-score estimation using tenure, usage, support calls, contract length and spend.
- Reviewed MAE, RMSE, feature importance and actual-versus-predicted plots to explain model behaviour.

## Results and limitations

Distinct from both IBM Telco classification and Wallace campaign response.

This publication currently contains a project description only. Source files and executable results are not included here.
