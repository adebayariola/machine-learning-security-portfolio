# Cybersecurity Event Forecasting

[← Portfolio home](../../../README.md) · [Data Analysis projects](../../../README.md#data-analysis)

> **Publication status:** Project summary; source not published.

## Research question

Can an LSTM forecast a monthly cybersecurity event count?

## Dataset

Course-generated monthly phishing, malware, suspicious URL and spam indicators

## Tools and methods

Python, LSTM, Dense output layers and Min-Max scaling

## What I implemented

- Built an LSTM forecasting workflow to estimate cybersecurity event count, using scaled numerical features and separate training and test sets.
- Converted predictions back to their original scale and examined errors and underestimation cases.

## Results and limitations

This is a forecasting case study, separate from PCAP malware detection.

This publication currently contains a project description only. Source files and executable results are not included here.
