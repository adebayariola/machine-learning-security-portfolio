> **Publication status:** Project summary; source not published.

## Research question

How can linked operational records produce useful festival and artist schedules?

## Dataset

Linked festival events, artists, venues, staff, bookings, repertoire and supplier records

## Tools and methods

Excel, Power Query M, VBA and linked Notion data

## What I implemented

- Combined linked operational records into a master festival backend using Power Query and prepared separate festival, artist and programme outputs.
- Implemented VBA routines for artist selection, date-filtered schedules and formatted programme outputs; packaged named query files and modules for maintenance and handover.

## Results and limitations

Desktop/Sound Festival Schedule Builder - Code Handover: VBA Code and Power Query Code; working macro-enabled workbook.

This publication currently contains a project description only. Source files and executable results are not included here.

Raw datasets, trained model binaries and private operational records are not redistributed. Dataset ownership remains with the respective providers. Where upstream research implementations were adapted, the description distinguishes those methods from local engineering contributions.
