# Okeowo Adewunmi — Machine Learning and Security Portfolio

Projects in network traffic analysis, malware classification, machine learning and data engineering.

## Download and run

Download [GitHub_Project_Portfolio.zip](GitHub_Project_Portfolio.zip) and extract it to retain each project’s original code directory structure and imports. The prefixed source files in this repository are browsing copies; run code from the extracted project directories. Dataset files must be obtained separately.

## Scope and reproducibility

46 Python source files and a housing notebook are included. Documentation-only entries are labelled. Raw datasets, model binaries and private operational records are excluded. Security draft scores are omitted pending verification. Adapted methods are identified in their project descriptions. No blanket license is assigned to third-party code or data.
