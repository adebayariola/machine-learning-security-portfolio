# Hotel Room Demand Forecasting

## Data
Course-generated monthly hotel-demand series; 100 observations

## Tools
Python, time-series decomposition, ADF testing, SARIMAX and Auto ARIMA

## Work completed
- Decomposed trend and seasonality, checked stationarity, applied differencing and examined ACF/PACF plots before fitting forecasting models.
- Compared SARIMAX and Auto ARIMA using a chronological train/test split, forecast errors and future-demand plots.

## Evidence and limitations
Generated-data coursework, not a production hotel dataset.

Raw datasets and private operational records are not distributed.

This entry documents the project; source code is not included in this publication.
